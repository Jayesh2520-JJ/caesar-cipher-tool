# 🔐 Caesar Cipher Encryption & Decryption Tool

## Overview

The Caesar Cipher Tool is a Python-based encryption and decryption application developed as part of the DecodeLabs Cyber Security Internship Program.

The application implements the Caesar Cipher algorithm, one of the earliest and most fundamental encryption techniques used in cryptography.

---

## Features

✅ Text Encryption

✅ Text Decryption

✅ User-defined Shift Key

✅ Uppercase Character Support

✅ Lowercase Character Support

✅ Preservation of Spaces

✅ Preservation of Numbers

✅ Preservation of Special Characters

✅ Validation of Decrypted Output

---

---

## How It Works

The Caesar Cipher shifts each alphabetic character by a fixed number of positions in the alphabet.

Example:

Plaintext:
HELLO

Shift Key:
3

Ciphertext:
KHOOR
